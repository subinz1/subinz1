# Selected projects

| Project | What it demonstrates | Links |
|---|---|---|
| Cross-Repository CI Relay | Event forwarding, OIDC-authenticated callbacks, DynamoDB/ClickHouse-backed HUD views, and tiered partner integration | [HUD](https://hud.pytorch.org/crcr) · [design work](https://github.com/subinz1/CRCR) |

| RHEL CI for PyTorch | Downstream nightly build/test pipeline, targeted test selection, and external relay reporting | [repository](https://github.com/TorchedHat/pytorch-redhat-ci) |
| PyTorch contributions | Core, CI, and out-of-tree backend work | [PyTorch](https://github.com/pytorch/pytorch) · [test-infra](https://github.com/pytorch/test-infra) |

Each project emphasizes an operational property in addition to implementation:
correctness, diagnosability, and a clear path from a failing signal to its
owner.
